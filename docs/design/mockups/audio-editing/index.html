Cut audio without touching the file

Cuts, takes, gain and fades become a list inside the clip. The audio files never change. Linked copies share the list, independent copies get their own, and a project becomes one file you can move anywhere.

Four questions

1. One file or a folder for a .tessera project?

One file means nothing can get separated. A folder keeps the project readable as text, and a missing folder could only warn you. Recommended: one file.

2. What should Delete do in the audio editor?

Del leaves a gap and Shift+Del closes it, or the other way round. Recommended: Del leaves a gap, so timing stays put, as Delete range does on the timeline.

3. Should every loop pass on an audio track be kept as a take?

Today the record mode decides, and in the default mode a new pass replaces the last. Recommended: always keep them. A lost pass can't be recovered.

4. Where does the choice of take live?

On the clip, so linked copies play one comp, or also on each tile. Recommended: on the clip. It matches your rule, and Make unique gives a different comp when you want one.
