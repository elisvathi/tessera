# 15. Keyboard shortcuts

Press **?** (Shift+/) in the editor to see this list on screen. On a Mac, use **Cmd** for **Ctrl** and **Option**
for **Alt**.

Keys act on the pane under the mouse. Keys marked *song pane* or *notes pane* only work there.

## Transport

| Key | What it does |
|---|---|
| Space | Play / stop |
| Shift+Space | Play from the mouse (or the selection's start) |
| R | Record |
| Ctrl+Shift+R | Capture what you just played as a clip |
| L | Loop on / off |
| Ctrl+L | Set the loop to the selection (clips, notes, steps or a range) |
| Ctrl+F | Follow the playhead |
| F1 (hold) | Fill |

## Tools

| Key | Tool |
|---|---|
| S or V | Select |
| D or B | Draw |
| P | Paint |
| E | Erase |
| C | Slice |
| T | Mute |
| Y | Velocity |
| Z (hold) | Zoom: drag a box, click to zoom in, Alt+click to zoom out |
| Alt+R | Range (*song pane*) |
| Ctrl+R | Step input |
| Ctrl+K | Keyboard play |
| Alt+A | Hear notes while editing |

## Editing

| Key | What it does |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |
| Ctrl+X / Ctrl+C / Ctrl+V | Cut / copy / paste |
| Ctrl+Shift+V | Paste at the mouse |
| Ctrl+D | Duplicate |
| Delete or Backspace | Delete |
| Ctrl+A | Select all |
| Ctrl+Shift+A | Select none |
| Ctrl+I | Invert the selection |
| Ctrl+E | Split |
| Ctrl+J | Glue |
| Ctrl+U | Make unique |
| Q | Quantize |
| Shift+Q | Quantize… (settings) |
| Up / Down | Transpose (a key step with scale snap) |
| Shift+Up / Down | Octave up / down |
| Left / Right | Nudge by one grid step |
| Shift+Left / Right | Nudge by one bar |
| Ctrl+Alt+Left / Right | Nudge by a fine step |
| Shift+Alt+Left / Right | Shorter / longer by one grid step |
| Ctrl+Alt+Up / Down | Velocity +5% / −5% |
| Ctrl+Alt+Shift+Up / Down | Velocity +1% / −1% |
| Alt+Left / Right / Up / Down | Select the next note in that direction |
| Ctrl+Shift+T | Transform box on / off (*notes pane*) |
| Ctrl+Shift+Delete | Delete time: the range closes up (*song pane*) |
| Shift+Delete | Delete parts of an audio clip and close the gap (*audio editor*) |
| Alt+T | Show or hide an audio clip's takes (*audio editor*) |
| Q / Shift+Q | Quantize hits with warp markers / its settings (*audio editor, or selected audio clips*) |
| Up / Down | The selected parts of an audio clip use the take above or below (*audio editor, takes showing*) |
| Ctrl+Shift+I | Insert silence as long as the range (*song pane*) |

## View

| Key | What it does |
|---|---|
| F | Zoom to fit |
| Z (tap) | Zoom to the selection |
| = or Num + | Zoom in |
| - or Num − | Zoom out |
| Ctrl+[ / Ctrl+] | Previous / next zoom |
| Home / End | Go to the start / end |
| Page Up / Page Down | Scroll one screen left / right |
| Shift+F | Fit all tracks (*song pane*) |
| Ctrl+1 / Ctrl+2 | Finer / coarser grid |
| Ctrl+3 | Triplet grid |
| Ctrl+4 | Snap on / off |
| Ctrl+Shift+F | Fold to the key's rows (*notes pane*) |
| I | Inspector |
| Tab | Switch pane (song, lower pane) |
| Shift+Tab | Maximize the pane, or restore the panes |
| F2 | Widen / narrow the clips beside the timeline |
| F3 | Devices: above the notes, or in their place in a short pane |
| F4 | Show the mixer or the notes in the lower pane |
| Ctrl+B | Bounce the selected track to a new track |
| Ctrl+Alt+E | Export audio |
| G | Drum lanes / keys (*notes pane*) |

## Tracks

| Key | What it does |
|---|---|
| Ctrl+T | Add an instrument track |
| Ctrl+Shift+T | Add a drum track (*song pane*) |
| Ctrl+G | Group the selected tracks (*song pane*) |
| Ctrl+Down / Ctrl+Up | Select the next / previous track |
| M | Mute the selected tracks |
| Alt+S | Solo the selected tracks |
| Shift+M | Turn the shown playhead off or on (*piano roll*) |
| Ctrl+M | Add a marker |

## General

| Key | What it does |
|---|---|
| ? (Shift+/) | Shortcut help |
| Ctrl+Shift+E | Export MIDI… |
| Ctrl+Shift+O | Import audio… |
| Esc | Cancel a drag, clear the selection, then close the editor |

## While keyboard play is on (Ctrl+K)

| Key | What it does |
|---|---|
| A S D F G H J K L | White keys |
| W E T Y U O P | Black keys |
| Z / X | Octave down / up |
| C / V | Softer / louder |

## While step input is on (Ctrl+R)

| Key | What it does |
|---|---|
| Right | Add a rest |
| Shift+Right | Make the last note longer (tie) |
| Left | Step back |
| Backspace | Remove the last step |
| Esc or Ctrl+R | Stop step input |

## Mouse

| Mouse | What it does |
|---|---|
| Alt while dragging | No snapping |
| Shift while dragging | One direction only, or fine values |
| Ctrl+drag | Copy what you drag |
| Ctrl+Alt+drag a timeline clip | Linked copy |
| Ctrl+drag from empty space | Selection box, with any tool |
| Shift+click / Ctrl+click | Add to / toggle in the selection |
| Alt+drag a note or a clip's body | Note: velocity. Timeline clip: slip the content. |
| Alt+drag a timeline clip's right edge | Time-stretch |
| Alt+Shift+drag a note's edge | Stretch the selection in time |
| Double-click | Open, or create |
| Right-click | Menu (Draw tool in the piano roll: delete) |
| Wheel / Shift+wheel | Scroll up and down / sideways |
| Ctrl+wheel | Zoom in time |
| Alt+wheel | Taller / shorter rows, around the mouse |
| Middle-drag or Space+drag | Pan |
| Alt+Shift+click a ghost note | Open its clip |
